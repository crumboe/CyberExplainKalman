Probability starts with a count

Suppose a student tries 100 practice questions and answers 77 correctly. These are example numbers for the lesson.

In the bag activity, a clue changed our guess. Here we will count a known group before changing the question.

\[P(\text{correct}) = \frac{\text{correct answers}}{\text{all questions}} = \frac{77}{100} = 0.77 = 77\%\]

The denominator answers: Which questions are we counting out of? Here it is all 100 questions.

Turn that count into a probability

\[\frac{10\text{ correct word problems}}{20\text{ word problems}} = 0.50 = 50\%\]

The bar | is read “given.” So \(P(\text{correct} \mid \text{word problem})\) asks: “What fraction were correct among the word problems?”

The denominator follows the question

For “correct given word problem,” we count out of the 20 word problems:

\[P(\text{correct} \mid \text{word problem}) = \frac{\text{correct and word problem}}{\text{word problem}} = \frac{10}{20} = 50\%\]

The word after given tells us which group goes on the bottom.

Reverse the question, change the answer

Now ask: “Of the 77 correct answers, how many were word problems?”

\[P(\text{word problem} \mid \text{correct}) = \frac{\text{correct and word problem}}{\text{correct answers}} = \frac{10}{77} \approx 13.0\%\]

The overlap is still 10. The denominator changed from 20 to 77.

Find the overlap another way

Start with the fraction answered correctly, then ask what fraction of those correct answers were word problems:

\[P(\text{correct and word problem}) = P(\text{correct}) \times P(\text{word problem} \mid \text{correct})\]

\[\frac{77}{100} \times \frac{10}{77} = \frac{10}{100}\]

The 77 cancels. We recover the same 10 overlapping questions out of 100.

Bayes’ rule connects the two questions

We wanted the chance of a correct answer among word problems. Use the overlap we just found:

\[P(\text{correct} \mid \text{word problem}) = \frac{P(\text{correct})\,P(\text{word problem} \mid \text{correct})}{P(\text{word problem})}\]

\[\frac{(77/100)(10/77)}{20/100} = \frac{10/100}{20/100} = \frac{10}{20} = 50\%\]

Bayes’ rule gives the same answer as counting directly. It is useful when we know the probabilities but cannot see every case in a table.

The short version so far

“And” means the shared cases. Here, that is 10 questions.

“Given” tells us which group to count inside. For word problems, that is 20 questions.

10 out of 20 = 50%. The long formula reaches the same answer.

Why would a cart need two guesses?

Imagine a cart moving along a straight track. We want to know where it is now.

  1. Guess from motion: Using its last known position and speed, we predict the cart is near 4 meters now. Its speed may have changed.
  2. Guess from a sensor: A sensor reports about 7 meters. The sensor may be noisy.

The two guesses disagree. Which one should pull our final answer more?

A first answer with ordinary algebra

The motion guess is 4 m. The sensor says 7 m. The gap between them is 3 m.

For this example, let the steadier sensor pull us three quarters of the way across that gap:

\[4 + 0.75(7-4) = 4 + 2.25 = 6.25\text{ m}\]

The answer is between 4 and 7, and closer to 7. Later we will calculate the 0.75 from how much each source tends to vary.

Remember only position

“It was at 2.0 m.” The estimate becomes stale as soon as the object moves.

Remember position and motion

“It was at 2.0 m and moving right.” Now we can make a useful prediction while the sensor is silent.

Motion carries the estimate forward. The next sensor reading pulls it back toward reality.

The “Trust Dial” Controls the Move

Dial near 0

Mostly trust motion

The sensor is unreliable, so the guess barely moves toward it.

Dial in the middle

Blend both

Both sources have value, so the answer lands between them.

Dial near 1

Mostly trust the sensor

The reading is dependable, so the guess moves close to it.

Updated guess = motion prediction + some fraction of the gap toward the sensor

Engineers call that fraction the Kalman gain. The filter calculates it from how much each source tends to vary.

Typical error versus squared spread

A camera might usually miss by about 0.10 m. We call that a typical error size.

To compare uncertainty in the trust-dial formula, the filter squares that size:

\[0.10\text{ m} \times 0.10\text{ m} = 0.01\text{ m}^2\]

If the typical error grows to 1.50 m, its square is 2.25 m². A big error produces a much bigger spread number.

Meters squared measures spread here. It is not another position along the track.

How the Filter Sets the Trust Dial

Sensor's share of the gapK = P⁻ ÷ (P⁻ + R)P⁻ is spread in the motion guess. R is spread in the sensor reading. They use the same units: m².
P⁻Motion spreadMore wheel slip raises this number.
RSensor spreadMore sensor noise raises this number.
KSensor influenceNear 0: little pull. Near 1: strong pull.

Our 4 m versus 7 m example

Suppose motion spread is 0.03 m² and sensor spread is 0.01 m².

K = 0.03 ÷ (0.03 + 0.01) = 0.75

Updated position = 4 + 0.75 × (7 − 4) = 6.25 m

If sensor spread R grows, K shrinks and the guess moves less. If motion spread P⁻ grows, K rises and the sensor gets more say.

Why the Combination Works Better

Motion only

It drifts

Tiny errors accumulate, so the predicted position slowly wanders away.

Sensor only

It jitters

Individual readings bounce around, even when the object moves smoothly.

Kalman filter

It stays smooth and grounded

Motion fills the gaps; sensors keep the prediction connected to reality.

A Kalman filter does not claim to know the exact truth. It keeps a best guess plus an honest measure of confidence, then improves both whenever new evidence arrives.

More Cameras Cannot Fix the Same Mistake

Imagine four cameras built with the same misplaced zero mark, like four rulers that all start 0.60 m too far right.

Separate random wobble

One camera's readings scatter by about 0.80 m. Averaging four independent readings cuts that typical wobble to about 0.40 m.

Shared wrong starting point

All four cameras are shifted 0.60 m the same way. Their average is still shifted 0.60 m.

Calibration checks the cameras against a known position and fixes the shared shift.

More cameras can calm random wobble. They cannot cancel a mistake they all share.
