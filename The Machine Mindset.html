Introduction: The Hidden State

Error is inescapable

What is 5 cm truely? Can we ever measure a perfect 5cm?

Yes and No

  • To a drill press : 5cm => 5cm +- .5cm
  • To a mill : 5cm => 5cm +- .005cm
  • To an ASML Photolithography Machine: 5cm => 5cm +- 0.000002cm

Today’s Goal

The Mathmatics of finding truth through Error, and incorporating new data as Evidence rather than truth. Since by definition we cannot measure the error of any particular measurment, We use probability to model the likelyhood of sensing a true value

Boolean vs. Probabilistic Logic

Boolean Logic

# Boolean logic example
# if (Shooter_will_make_the_shot == True):
#     shoot

Probabilistic Logic

# Probability logic example
# if (Probability_we_make_the_shot >= 80%)
#     shoot

Key difference:

Combining evidence with trust levels enables better decisions.

  • Boolean: Instantaneous sensor read → immediate judgment

  • Probabilistic: Averages sensor noise, reduces false positives/negatives

Caveat:

There are alternative filtering approaches that don’t rely on probability:

  • Rolling average on distance sensors
  • Debounce period on limit switches
  • Moving median filters
  • Exponential smoothing
  • These can work very well depending on implementation and use case

Understanding Set Space

  • We want a number that represents how often something happens, or does not
  • If you know nothing about an event, you could assume it’s a 50:50 chance, pass or fail, it will happen or it wont
  • With Evidence about the type of event (I.E. Rolling a 2 on a D6 Die) you can refine your guess, in this case to 1:6
  • You can also experiment to find probability. If given a weighted die, you could roll it many times to gather data, and hone in on the true likelyhood of any given face landing up.

Bayes Theorem – Generally

\[P(\text{Event} \mid \text{Evidence}) = \frac{P(\text{Event} \cap \text{Evidence})}{P(\text{Evidence})}\]

\[P(\text{Evidence}) = \frac{P(\text{Event} \cap \text{Evidence})}{P(\text{Event} \mid \text{Evidence})}\]

\[P(\text{Event} \cap \text{Evidence}) = P(\text{Evidence}) \times P(\text{Event} \mid \text{Evidence})\]

Understanding Set Space

Bayes Theorem – Generally

For events that are dependent, finding The intersection (AND) can be difficult. So Bayes tells us =>

\[P(\text{Evidence} \cap \text{Event}) = P(\text{Event}) \times P(\text{Evidence} \mid \text{Event})\]

So we substitute and rewrite the our original equation as:

\[P(\text{Event} \mid \text{Evidence}) = \frac{P(\text{Event}) \times P(\text{Evidence} \mid \text{Event})}{P(\text{Evidence})}\]

Understanding Set Space

Bayes Theorem – Generally

For events that are dependent, finding The intersection (AND) can be difficult. So Bayes tells us =>

\[P(\text{Event} \mid \text{Evidence}) = \frac{P(\text{Event}) \times \text{Likelihood of this evidence given the event happening}}{P(\text{Evidence})}\]

How Evidence Accumulation Works:

• Start with Prior Belief: P(Event) - our initial confidence before new evidence

• Update with Evidence: Each new observation becomes “Evidence,” and we set up a way of determining if this evidence is likely

• Calculate New Confidence: The posterior P(Event|Evidence) becomes our new prior for the next update

• Iterative Process: Previous posterior → new prior → collect evidence → update → repeat

This creates a feedback loop where reliable evidence strengthens our confidence, while contradictory evidence appropriately weakens it, leading to increasingly accurate beliefs over time.

Activity: Bayes and the Broken Motor

Setup

  • Box A (Good Motor): 36 Green beads (90%), 4 Red beads (10%)
  • Box B (Bad Motor): 20 Green beads (50%), 20 Red beads (50%)
  • Student draws a bead from a randomly chosen box.

Scenario

Suppose a student draws a red bead. What is the probability it came from Box B?

Bayes Calculation

\[ P(\text{Box B} \mid \text{Red}) = \frac{P(\text{Red} \mid \text{Box B}) \cdot P(\text{Box B})}{P(\text{Red})} \]

Activity: Bayes and the Broken Motor

Step 1: Priors
\(P(\text{Box A}) = 0.5\)
\(P(\text{Box B}) = 0.5\)

Step 2: Likelihoods
\(P(\text{Red} \mid \text{Box A}) = \frac{4}{40} = 0.10\)
\(P(\text{Red} \mid \text{Box B}) = \frac{20}{40} = 0.50\)

Step 3: Total probability of red bead
\(P(\text{Red}) = 0.10 \times 0.5 + 0.50 \times 0.5 = 0.05 + 0.25 = 0.30\)

\[ P(\text{Box B} \mid \text{Red}) = \frac{P(\text{Red} \mid \text{Box B}) \cdot P(\text{Box B})}{P(\text{Red})} \]
